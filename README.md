# Student Grade Management System

## Overview

Student Grade Management System is a simple Python-based project used to
manage student grades.

The system allows users to add, update, delete, view, and search student
grade records through a command-line interface.

## Features

- Add Student
- Update Student
- Delete Student
- View All Students
- Search Student
- Grade Validation
- Error Handling

## Technologies Used

- Python
- VS Code
- Git
- GitHub
