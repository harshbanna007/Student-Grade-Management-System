# Student Grade Management System

## Problem Statement

Managing student grades manually can be time-consuming and may lead to errors.
The Student Grade Management System provides a simple way to add, update,
delete, view, and search student grades.

## Scope

The project is designed for basic student grade management.
It provides a simple command-line interface for maintaining student names
and their grades.

## Target Users

- Teachers
- Faculty members
- Students

## High-Level Features

- Add student
- Update student grade
- Delete student
- View all students
- Search student
- Grade validation
- Error handling
